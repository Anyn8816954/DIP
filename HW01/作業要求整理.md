### C. 醫學影像的空間濾波增強，30%（第 9–20 頁）

完成 `spatial_operations.py` 與 `medical_enhancement.py`。

| 函式 | 必要要求 | 報告要附的內容 |
| --- | --- | --- |
| `convolution` | 自行實作，不能用第三方卷積 API，例如 `np.convolve`；依核心半徑做 zero padding，以兩層 for 迴圈逐位置運算 | 補零後影像、指定 3×3 測試的輸出 |
| `box_filter` | 核心為 `(2r+1)×(2r+1)`，權重總和為 1；呼叫自行實作的卷積 | 使用的 Box kernel |
| `laplacian_filter` | 使用 3×3 核心，從講義中選中央係數為正的兩種核心之一；呼叫自行實作的卷積 | 使用的 Laplacian kernel |
| `sobel_filter` | 使用兩個 3×3 Sobel 核心，算出 `gx`、`gy`，再以 `sqrt(gx²+gy²)` 計算梯度大小 | 兩個 Sobel kernels |
| `image_product` | 正規化後逐像素相乘；可使用 NumPy | 程式及說明 |
| `image_sum` | 正規化後逐像素相加，映回後截斷超過 255 的值；可使用 NumPy | 程式及說明 |

依骨架處理浮點運算、正規化、強度範圍截斷及 `uint8` 輸出。

**指定的卷積測試（第 14 頁）**

```text
輸入影像：             核心：
[[1, 2, 3],            [[-1/7, 1/7, 1/7],
 [4, 5, 6],             [-1/7, 1/7, 1/7],
 [7, 8, 9]]             [ 1/7, 1/7, 1/7]]
```

報告須列出此測試的輸出，不能只跑一般照片。

**醫學影像處理流程（第 10–11 頁程式骨架）**

1. 讀取 `pxhere-mouth.jpeg`，轉為灰階。
2. 原圖分別做 Laplacian 與 Sobel。
3. 對 Sobel 梯度影像做 Box filtering，`radius = 2`，即 5×5。
4. 原圖加 Laplacian，得到 `sharpened_image`。
5. Laplacian 影像乘平滑後梯度影像，得到 `mask_image`。
6. 原圖加 mask，得到 `denoised_sharpened_image`。
7. 最後做 Gamma 轉換，骨架給定 `c = 1`、Gamma 指數 `0.5`。

**必要比較與討論（第 12 頁）**

- [ ] Laplacian 影像與梯度影像的細節差異。
- [ ] Laplacian 影像與 mask 影像的細節差異。
- [ ] 原圖、銳化圖、`denoised_sharpened_image` 三者的細節差異。
- [ ] 再用 **`wellcome-skull.png`** 完成相同處理與上述比較。

建議保留兩張圖片的所有中間結果，以支撐報告比較。
